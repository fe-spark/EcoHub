正式版，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.4.2` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **从 v2.4.1 升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。

---

### 核心变更

#### 1. 访问分析：终端渠道与业务场景画像重构

- **终端渠道看板**：原「终端设备分布」重构为「终端渠道分布」进度看板，展示各渠道（Web网页端、TVBox电视、App客户端、爬虫等）角色特征说明、请求量与百分比进度条，右上角明确标出「总请求量: X 次」，并增加口径说明 Tooltip，彻底消除概念歧义。
- **业务场景画像**：升级「业务场景画像」环形图与图例排版，环心明确标为「操作总量: X 次」，右侧图例引入加长至 72px 的彩色占比进度条，比例梯级对比更鲜明直观。
- **完全垂直居中**：解决图表卡片内内容未垂直居中及底部留白问题，卡片内容在不同高度下始终严格垂直正中对齐。

#### 2. 响应式与防溢出排版

- **图表容器尺寸感知**：Donut 环形图接入容器尺寸监听，在不同屏幕宽度下自适应缩放直径，窄屏模式下自动优化图例排版，杜绝文字溢出。
- **热力图横坐标边界对齐**：修复服务响应耗时分布（时序热力图）右侧横轴时间标签（如 `12:15`）贴边溢出问题，重构 X 轴刻度与 Y 轴及网格边界像素级对齐。
