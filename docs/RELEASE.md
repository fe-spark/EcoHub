预发布版 **v3.0.0-beta.2**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.2`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.2`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据**！旧版数据结构已被彻底废弃推翻，请勿直接挂载 v2.x 历史数据库升级；建议全新部署或清空旧数据库后启动并重新配置采集站。

---

### v3.0.0-beta.2 核心变更

- **切换首选站原地复用检索索引**：首选主站切换不再销毁重构 58 万条全局内存倒排索引，原地复用已有大索引并秒级预热新首页视图，切换生效耗时由 39 秒骤减至 50 毫秒（提速 700+ 倍），彻底消除重构引发的内存暴涨与 CPU 尖刺。
- **采集站编辑任务校验精准化**：修改采集站 URL 或数据协议时，由原先的全局一刀切拦截（`IsAnyTaskRunning`）精准收窄为仅校验当前被修改的站点，其他站点正在采集或有定时任务时不阻碍本站配置更新。
- **大片库索引封口与构建大幅提速**：
  - 消除 58 万条影片在封口阶段的重复标题正则清洗与归一化计算；
  - 倒排索引构建采用 Go `slices.SortFunc` 替代反射排序，并消除分词去重中的 230 万次小堆 Map 分配；
  - 增加倒排索引尾部查重防御，彻底杜绝极端超长片名可能导致的检索结果重复。
- **终止采集状态与上次运行信息闭环**：覆盖 `done`、`stopped`、`failed` 全终态流式推送与数据库实时落盘，0 页正常结束或中途终止均完整记录。
- **采集站异步级联删除与实时进度**：删除采集站接入后台异步队列与 SSE 实时广播，顶部实时显示级联删除进度条与实际删除影片总数，提交失败即时拦截防假死。
- **纯净本地数据重置**：数据重置彻底零外网 HTTP 请求依赖，物理清空片库业务数据同时完整保留本地分类库与映射字典，杜绝因外部采集站失效或 403 导致重置中断的问题。
