预发布版 **v3.0.0-beta.5**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.5`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.5`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.5 核心变更

- **全量采集不再每页重建检索索引**：17 万级片库重采时，不再每入库几百部就复制、重排并重建整库倒排。采集过程中检索仍用上一版索引。队列结束后延后 2 秒，由单一重建器整库重建一次。多个队列同时结束只合并成一轮；扫描期间又有队列写完，会立刻再扫一轮，不会互相覆盖。
- **播放线路按真实分隔符切开**：采集站把 `vod_play_note` 填成一长串 `$` 时，不再拿它当分组符。地址里实际是 `$$$` 就按 `$$$` 切。已入库的合并列表不迁移，重新采集后生效。
- **播放器弹幕**：支持本站弹幕发送与按进度展示。Seek 后按当前时间重排在途弹幕。后台可开关弹幕，并配置弹弹play 嗅探；非管理员接口不返回密钥。
