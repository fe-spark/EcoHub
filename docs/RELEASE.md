正式版，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.4.4` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **从 v2.4.3 升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。无需额外迁移。

---

### 核心变更

#### 1. 首页分类推荐动态随机池

- **动态热播候选池**：首页各分类推荐卡片由固定前序展示升级为近 1 个月各分类高热度影片池（Top 50）每次访问动态随机抽样 14 部展示，有效增加首页内容曝光流动性与发现感。
- **平滑降级兼容**：若近一个月内无最新热播数据，自动平滑回退至全量历史热度排序池抽样，避免空白。

#### 2. 搜索与相关度召回优化

- **召回与打分调优**：优化模糊搜索候选召回倒排索引与字段打分策略，进一步提升长短词与首字母搜索的精准度。
- **分页状态联动**：修复搜索结果翻页时搜索框及地址栏参数未完全同步的问题。

#### 3. 性能与前端交互体验优化

- **暗色主题适配**：修复后台暗色模式下一键升级二次确认弹窗的样式与视觉对比度。
- **系统日志流增强**：优化管理后台系统实时日志流游标渲染同步与展示精度。
- **图表与动画容错**：优化首页每日更新离子动效切换与定时器生命周期管理，增强网络波动下的容错表现。
- **工作台概览精简与去轮询**：精简管理后台首页运行概览指标项，移除未实时更新的瞬时状态与无谓的高频短轮询开销。
- **鸿蒙客户端子模块更新**：更新 HarmonyOS 客户端 `app-for-ohos` 至 v1.1.3 版本。
