预发布版 **v3.0.0-beta.16**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.16`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.16`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.16 核心变更

- **用户更新与个人资料修改架构重构**：
  - 严格遵循 `handler -> service -> repository` 垂直调用分层，原密码比对与个人资料修改完整下沉至领域服务层 `UserService.UpdateProfile`，根除 Handler 跨层直调持久层；
  - `UserUpdatePayload` 增强 JSON 反序列化解析能力，容错兼容字符串与大小写 `ID`/`id` 传递，统一规整并保证类型安全；
  - 补充超管更新用户时兼容各类 ID 格式的单元测试，提升接口健壮性。
- **影片抽屉与播放线路回显深度重构**：
  - 彻底拆分重构 `FilmDrawer`，将复杂表单数据组装与多线路保存逻辑抽离至独立工具函数，严格控制单文件在 500 行以内；
  - 修复影片抽屉切换线路时播放直链回显逻辑，优先取当前线路编辑缓存，缺失时回退默认序列化直链，避免多源多线路直链展示不同步。
- **采集任务与队列终止体验优化**：
  - 单站点终止操作补齐异常捕获防护，终止失败时即时重置卡片状态并弹出明确错误提示，杜绝界面死锁在「正在停止...」；
  - 队列停止前置运行中站点判定，无正在运行任务时即刻反馈「采集已终止」并清除停止态，消除多余的异步等待。
- **移动端多端子模块更新**：
  - 同步 Android 与 HarmonyOS 客户端最新提交，更新推荐链接并优化播放与客户端构建配置。
