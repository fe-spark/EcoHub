正式版 **v2.5.6**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.5.6` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **从已有版本升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。
- **兼容性说明**：本版本完全向下兼容现有 MySQL 与 Redis 数据结构，无破坏性变更。

---

### v2.5.6 核心变更

#### 1. 高频分类全部记录弹窗与看板渲染修复
- **分类专属展示与名称优先**：修复后台「高频分类 TOP 10」查看全部弹窗中由于缺少分类专属渲染分支导致仅展示原始数字 ID 且误跳搜索页的问题，优先展示真实分类名称（未命中时优雅兜底为 `分类 #ID`）。
- **分类 ID 标签直观呈现**：分类条目在具有真实名称时附加专属 `#{ID}` 标签，支持点击直接新标签页跳转对应分类筛选页（`/filmClassify?Pid={id}`）。
- **色彩与主题视觉统一**：弹窗头部图标统一采用绿色分类图标 `<AppstoreOutlined />`，频次柱状图及数值采用分类专属主题绿色（`#52c41a` / `#73d13d`）。

#### 2. 后端访问分析与分类元数据解析加固
- **分类名称解析防缓存穿透**：`resolveCategoryNames` 为未命中的分类 ID 自动记录占位符缓存，防止无效或历史已删除分类高频穿透打库。
- **每日离线归档元数据补齐**：每日 Rollup 离线统计落库 `access_daily_tops` 时自动补全分类名称元数据，保障历史看板与实时看板展示完全一致。
