预发布版 **v3.0.0-beta.11**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.11`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.11`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.11 核心变更

- **数据分析配置后台化与动态热启停**：
  - 彻底废弃宿主环境变量 `ACCESS_ANALYTICS_ENABLED`，不再需要在 Compose 中注入；
  - 数据分析改为管理后台动态开关，支持内存原子状态单指令（<1ns）热生效，零 I/O 零延迟放行；
  - 功能收归至「系统运维 $\rightarrow$ 数据安全」一体化管理；未开启时自动隐藏侧边栏「数据分析」入口，保持菜单整洁；
  - 「清理历史统计数据」支持空数据自动置灰与留存统计精确提示；
  - 系统配置备份与恢复新增「数据分析」模块支持。
- **弹幕配置独立卡片与级联互锁**：弹幕设置从基础配置抽离为独立配置卡片，新增专用管理路由与非管理员脱敏；交互支持自动嗅探与 AppId/AppSecret 条件联动，未开启嗅探或使用自定义 API 时免填凭据。
- **数据安全配置备份与分析清理加固**：
  - 配置导入前强制阻断新采集并等待在途任务与快照彻底排空，写入前严格校验所有选中模块，杜绝部分写入；计划任务先写库再切运行时，采集站或规则导入后自动同步刷新分类映射与读模型投影。
  - 数据分析清理调整为先 Redis 匹配删除再提交 MySQL 事务，全量清空增加二次扫描防漏键。
  - 配置导出改为强制校验管理密码，防止敏感集成密钥与订阅凭据直接泄露。
- **计划任务真实执行时间与低频优先**：计划任务“上次执行时间”严格按实际开工时刻计算，排除排队与维护让路耗时；片库孤儿清理支持独占维护闸门，采集自动让路且支持弹性超时。
- **工作台片库统计口径重构**：移除无实际业务意义的“展示分类”指标，重新对齐片库影片与多源聚合统计。
