预发布版 **v3.0.0-beta.0**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.0`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.0`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据**！旧版数据结构已被彻底废弃推翻，请勿直接挂载 v2.x 历史数据库升级；建议全新部署或清空旧数据库后启动并重新配置采集站。

---

### v3.0.0-beta.0 核心变更

- **片库独立建档与基准源严格对齐**：彻底推翻旧版聚合存储模型，各采集站数据物理独立建档存储，杜绝多源串联混杂；前台首页、分类专区、片库检索与 TVBox 严格对齐首选站（基准源）展示与路由，跨源线路在播放时按匹配键自动关联。
- **检索与首页改走内存倒排索引**：片库检索与分类榜单彻底切入内存索引，后台异步流式加载并收紧常驻内存；支持首选站首页快速点查与预热，杜绝全表冷查询。
- **采集中心升级为 SSE 实时流**：采集任务全面改造为 SSE 实时流式进度推送，支持动态并发调度、限流退避与断线重连；批量采集改用抽屉工作台，失败记录即时原行推送。
- **首页轮播重构为排片工作台**：轮播列表重构为卡片拖拽与一键排片抽屉，支持基于首选站分类的批量刮削与 TMDB 独立元数据存储策略。
- **管理后台全量抽屉化与交互收口**：全局弹窗统一重构为抽屉组件，优化影片详情编辑、分类树级联与采集站关联配置；表格高度自适应并收口按钮文案。
- **多端设备鉴权与稳定性加固**：支持多端与多设备并发登录会话管理；强化采集与入库终态一致性，失败重试严格保留原数据；移除 Telegram 遗留配置。
