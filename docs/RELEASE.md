预发布版 **v2.5.5-beta.1**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.5.5-beta.1`。

### 升级指引

- **从已有版本升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。
- **兼容性说明**：本版本完全向下兼容现有 MySQL 与 Redis 数据结构，无破坏性变更。

---

### v2.5.5-beta.1 核心变更

#### 1. 数据分析与流转看板全新重构 (Web / 移动 App / TVBox)
- **多端业务看板独立呈现**：新增 Web 独立视图、App 移动端独立视图（支持 Android/HarmonyOS/iOS 切换过滤）与 TVBox 大屏专属视图，彻底解耦用户行为与系统运维日志，各端独立度量 PV/UV、停留深度、设备系统分布与流转轨迹。
- **全量排行榜与无界洞察**：“热门点播”与“热门搜索”卡片右上角新增“查看全部”入口，支持模糊检索、动态分页（10/20/50/100 条）与平滑换页，彻底解除 Redis 200 条硬截断限制。
- **设备身份与机型精准识别**：客户端路由拦截器结合设备指纹沙箱持久化，鸿蒙原生端支持提取商业机型（如 `HUAWEI Mate 60 Pro`），流转日志告别 `-` 空白展示。

#### 2. 全新【接口访问记录】审计体系与高并发落库加固
- **业务与运维审计彻底解耦**：接口访问记录收归至系统设置内独立维护（`/manage/system?tab=api-logs`），专注全站对外 HTTP 接口健康度、错误率（4xx/5xx）、慢请求跟踪与安全回溯。
- **运存与磁盘物理硬顶保护**：异步无界非阻塞缓冲（chan 2000，内存开销 < 2MB）+ 100 条批量聚合刷盘，主请求链路 0 阻塞、0 延迟。
- **后台自动修剪与定时滑动窗口**：系统内置 Model 4 定时任务每日凌晨 3:00 分批修剪 7 天前过期记录，具备并发防重互斥与单次批次上限保护，物理锁定磁盘容量天花板（约 20~30MB）。
- **高并发生产级容灾加固**：
  - 批量写 Worker 增加连续失败毒丸熔断机制，杜绝异常报文导致全局写协程卡死；
  - 优化时间复合索引与分页排序为 `created_at DESC, id DESC`，杜绝 MySQL 优化器误选主键倒序全表扫描；
  - 移除非必要单列索引，彻底消除批量插入时的写放大与 InnoDB 缓冲池负担。
