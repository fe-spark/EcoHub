正式版 **v2.3.0**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.3.0` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **从 v2.1.x / v2.2.x 升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。
- **从 v2.1.0 之前升级**：请先按 [v2.1.0 说明](https://github.com/fe-spark/EcoHub/releases/tag/v2.1.0) 完成素材卷目录迁移，再升级到本版本。

---

### v2.3.0 核心变更

#### 1. 每日更新体系重构与分类分页架构
- **分类聚合与标准分页**：服务端新增 `DailyUpdatesV2` 接口，支持按导航大类聚合、标准分页与随机抽取模式，同时完全兼容旧版 `/index/dailyUpdates` 接口。
- **离子碎片渐进式汇聚与动效优化**：
  - 优化为渐进式独立汇聚：卡片图片加载完成后立即独立汇聚成型并展现真实 DOM，消除全局阻塞等待机制；
  - 离子散开升级为随机格点置换算法（动画时长提升至 480ms），散开更自然且彻底消除原图轮廓残留；
  - 修正像素特效与卡片底部遮罩层级，杜绝盖住标题与文案；
  - 切换数据时首个影片文案与标题在拉取到新数据后即刻平滑更新。
- **后台页面休眠保护**：监听 `visibilitychange` 事件，切到后台标签页时自动挂起轮询定时器与粒子动画，切回前台平滑恢复，避免无效资源消耗与 rAF 定格异常。

#### 2. 片库专区与检索页面深度重构
- **filmClassify 专区页**：引入 Hero 专区氛围卡片、精选/片库 Tab 联动及「最新上映 / 热度排行 / 最近更新」精选专题卡片流，带来沉浸式浏览体验。
- **filmClassifySearch 片库检索页**：重构筛选面板与标签胶囊交互，支持一键重置筛选与专区 Tab 快捷跳转。
- **UI 规范严格对齐**：全量遵循 8pt 间距网格与主题色彩规范，消除 `!important` 样式层级问题。

#### 3. 全站 Header 与全端搜索体验升级
- **Header 搜索精简与自适应分类**：顶部搜索框优化为精致图标入口，点击直达搜索页或自动聚焦输入框；快捷分类导航按可用宽度自适应展示，超长项自动收纳进分类全览；优化移动端历史记录抽屉全屏适配。
- **搜索页面重构**：搜索页支持全端全宽搜索框、空搜自动聚焦、热门搜索榜单联动与最近搜索历史记录快速检索。

#### 4. 鸿蒙客户端升级 (v1.1.0)
- **子模块同步升级**：同步 `app-for-ohos` 至 v1.1.0 正式版本。
- **多端特性对齐**：支持 SplashPage 启动探活、每日更新分类 Swiper 联动、上滑瀑布流加载更多等体验优化。
