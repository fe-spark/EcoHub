预发布版 **v2.7.3-beta.6**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.7.3-beta.6`。

### 升级指引

- **平滑升级**：支持后台「检查更新」一键平滑升级，或通过 `docker compose pull ecohub && docker compose up -d ecohub` 快速拉取新镜像。
- **配置持久化**：系统配置、TMDB 刮削凭据与影片元数据持久化存储，平滑升级无需重新初始化。
- **存量播放源对齐**：升到本版后再跑 `docker exec -it Eco-hub /app/migrate_slave_playlist_keys --dry-run`，确认后去掉 `--dry-run`。上一轮迁到一半可直接重跑，已归并的行会跳过。同一豆瓣号、两部不同片名（如「沧元图3D动漫版」与「沧元图 动态漫画」）需在后台对该片执行「更新全部站点」，不必全量重采所有附属站。

---

### v2.7.3-beta.6 核心变更

- **附属站搜索进播**：源站卡片不再只凭映射进主站播放页。同名片名、剧集形态或大类对不上，或两个 `vod_id` 落到同一个本地 mid，改为 `/play/live` 播该源自己的片子。

---

### v2.7.3-beta.5 核心变更

- **附属站搜索卡片**：`ac=list` 与 `ac=detail` 只按 `vod_id` 对齐，不再用本地快照海报覆盖同名片名。大类和更新状态以列表为准；海报、年份、主演、简介、剧情标签来自该 id 的详情。同名片名、不同 id 或大类是两张卡。

---

### v2.7.3-beta.4 核心变更

- **采集队列**：批量全量时排队中的站点不再被 30 分钟超时误标失败、拆成 `__none` 队列。失败或跳过会立刻释放占用，重试开新队列，不会再报「已在采集队列或正在运行」。
- **附属站搜索**：只把源站明确返回「暂不支持搜索」缓存 30 分钟；维护中等其它短文本不再误缓存。搜索结果带回 `error`，前台对应 Tab 展示原因。
- **现场播放**：`/play` 只走本地入库影片；源站直连改为 `/api/liveFilmPlayInfo`，另提供同源同类 `/api/liveFilmRelate`。`/play/live` 独立布局（标题条 + 播放器/选集分栏 + 简介 + 同源推荐），不再复用主站播放页。

---

### v2.7.3-beta.3 核心变更

- **迁移脚本加速**：扫描播放列表不再拉取正文 JSON；归并改为按主键批量删除。默认批次 2000，每 2 万行打一次进度。
- **可中断重跑**：已写到新主键的行会跳过，不必等旧脚本跑完。

---

### v2.7.3-beta.2 核心变更

- **播放源绑定改为绑或不绑**：不再对候选打分。附属站规范化片名与主站全等才考虑绑定。
- **一票否决仅在两边都有值时生效**：豆瓣 ID、年份、导演、剧集结构任一边空或未知不否决。否决后主站只剩一部这个名字 → 直接绑。
- **同名多部再挑选**：依次看豆瓣 ID、大类、年份（同年，其次差 1 年）是否只对上一部；对不上就不绑。同一豆瓣号不再跳过年份/导演检查。
- **详情页**：已经绑上的源直接展示，不再用线路结构二次过滤。

---

### v2.7.3-beta.1 核心变更

- **跨站播放源绑定**：豆瓣 ID 相同不再视为同一部，必须片名也一致；「沧元图3D动漫版」与「沧元图 动态漫画」各挂各的线路。
- **片名规范化**：匹配键与认片均去掉片尾进度 / 清晰度 / 语种噪音（更新至、第 N 集、国语、普通话、1080P 等），繁简与大小写先折叠；保留剧场版、3D、动态漫画等版本身份。年份片名不会被剥空。
- **剧集**：不再按集数接近度打分。只保留形态门槛（无集号单条对不上长剧；打包区间对不上差太远的逐集）。

---

### v2.7.3-beta.0 核心变更

- **附属站搜索与多采集源直连**：
  - 搜索页面支持聚合搜索与各启用采集源（主站/附属站）Tab 联动无缝切换，附属站直接调用源站 MacCMS 搜索接口实时检索，主站未收录影片亦可直接搜到。
  - 采集源 Tabs 并发异步拉取各源结果数与动态加载指示，解决切换到非主采集站刷新页面或直接访问特定源时 Tabs 消失的问题。
  - 修复 `GetEnabledCollectSourceList` 数据库句柄空指针防御，增强单源搜索在各种环境下的稳定性。
- **现场实时播放（Live Play）体系**：
  - 附属站独有资源未命中本地快照时自动进入 `/play/live` 现场播放页，直接读取采集源 MacCMS 播放数据，不落库、不污染主站快照体系与孤儿表。
  - 现场播放详情封面相对路径由源站基础 URI 自动补全，避免第三方图源解析失效。
  - 完善剧集负数与越界保护，防止异常播放参数引发服务异常。
- **UI 与交互体验优化**：
  - 修复搜索加载状态（`<AppLoading />`）与结果列表结构重叠的问题，规范定位与盒模型。
  - 移动客户端子模块（Android / OpenHarmony）同步至最新对应版本提交。
