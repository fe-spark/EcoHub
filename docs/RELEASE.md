预发布版 **v3.0.0-beta.6**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.6`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.6`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.6 核心变更

- **修复运行日志恢复推送延迟 15 秒**：修复日志流在暂停后恢复推送时，因无增量日志且缺少首包帧，导致反向代理缓冲等待 15 秒心跳才建立连接的问题；SSE 连接建立即刻下发 ready 握手帧，恢复推送秒级就绪。
- **修复非采集路径搜索倒排同步**：修复后台影片手动修改、TMDB 元数据补全等增量更新路径下搜索倒排索引未同步构建的缺陷，修改片名后前台搜索立即可见。
- **索引重建协程同步与防并发锁**：索引异步重建器接入生命周期追踪，并与冷启动索引构建共用互斥锁，避免并发重复全表扫描及内存重复开销。
- **首页热播榜单样式调优**：修复分类热播排行列表项 hover 高亮时序号紧贴背景边缘的问题，补齐内边距并对齐标题图标。
