预发布版 **v3.0.0-beta.8**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.8`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.8`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.8 核心变更

- **采集批量删除提示收敛与体验对齐**：彻底修复采集中心多选批量删除站点时，因前端监听逐站 SSE 回调导致屏幕瞬间弹出一二十条“删除成功”Toast 堆叠的缺陷。移除单站事件的侵入式弹窗，全面对齐采集队列的进度承接机制；删除过程全程由顶部删除队列进度条统一展示（包含级联清理状态、完成站点数及已清理影片档案总数），仅在队列全部执行完毕时统一下发单条带唯一键的汇总通知，保障界面干净利落。
