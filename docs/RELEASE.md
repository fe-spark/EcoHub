预发布版 **v3.0.0-beta.4**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.4`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.4`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；采集站 `vod_play_note` 修正后，重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.4 核心变更

- **播放线路按真实分隔符切开**：采集站把 `vod_play_note` 填成一长串 `$` 时，不再拿它当分组符。地址里实际是 `$$$` 就按 `$$$` 切。爱旦「时光代理人第三季」这类源会得到 8 条线路，而不是粘成 65 集。已入库的合并列表不迁移，重新采集后生效。
- **播放器弹幕**：支持本站弹幕发送与按进度展示。Seek 后按当前时间重排在途弹幕，全屏与窗口使用不同飞行时长。后台可开关弹幕，并配置弹弹play 嗅探与 AppId；非管理员接口不返回密钥。
- **检索倒排增量重建**：影片改名或增量更新后按当前片库重建倒排，避免多字检索漏结果。
- **采集失败收口**：总页探测失败会标成 failed 并释放占用。失败页重试不再把上一轮停止状态当成这次停止；取消中的重试不扣重试次数。
