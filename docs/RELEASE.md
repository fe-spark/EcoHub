预发布版 **v2.5.5-beta.2**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.5.5-beta.2`。

### 升级指引

- **从已有版本升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。
- **兼容性说明**：本版本完全向下兼容现有 MySQL 与 Redis 数据结构，无破坏性变更。

---

### v2.5.5-beta.2 核心变更

#### 1. TVBox 接口调用分布全新可视化重构
- **全景分段比例胶囊条**：顶部 14px 满宽圆角比例条，平铺展现寻片搜索、分类列表、影视点播与源配置同步的流量构成切片，悬停智能聚光并支持 Tooltip 提示。
- **横向胶囊排行条形列表**：替代原有空旷竖向柱状图，按调用量动态降序展示排名徽章（#1、#2、#3）、语义图标、调用次数与高亮百分比 Badge。
- **全量无界双向联动**：顶部比例条与下方卡片行实现双向 Hover 聚焦与动态投影交互。

#### 2. 多端访问统计与客户端生态协议对齐 (Android & 鸿蒙)
- **多端业务看板独立呈现**：Web 独立视图、移动 App 独立视图（Android/HarmonyOS/iOS 切换过滤）与 TVBox 大屏专属视图，各端独立度量 PV/UV、停留深度与流转轨迹。
- **客户端设备指纹与路由流转追踪**：Android 与鸿蒙客户端对齐路由拦截器与设备指纹沙箱持久化，精准识别商业机型与页面流转。
- **全量排行榜无界洞察**：“热门点播”与“热门搜索”卡片支持模糊检索、动态分页与平滑换页，解除 Redis 200 条硬截断限制。

#### 3. 全新【接口访问记录】审计体系与高并发落库加固
- **业务与运维审计彻底解耦**：接口访问记录收归至系统设置内独立维护（`/manage/system?tab=api-logs`），专注对外 HTTP 接口健康度、错误率（4xx/5xx）与慢请求跟踪。
- **运存与磁盘物理硬顶保护**：异步非阻塞缓冲（chan 2000，内存开销 < 2MB）+ 100 条批量聚合刷盘，主链路 0 阻塞、0 延迟。
- **后台自动修剪与定时滑动窗口**：每日凌晨 3:00 分批修剪 7 天前过期记录，具备并发防重互斥与单次批次上限保护。
- **高并发生产级容灾加固**：批量写 Worker 增加连续失败毒丸熔断机制，优化时间复合索引与分页排序为 `created_at DESC, id DESC`。
