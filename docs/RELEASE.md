预发布版 **v3.0.0-beta.23**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.23`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.23`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.23 核心变更

- **一键排片策略对齐与体验一致性**：
  - 修正一键排片配置抽屉与审核抽屉中排片策略文案，将「最新上线」统一对齐为「最近更新」；
  - 选片逻辑与 `/category/filter` 分类页全面对齐，后端服务层增加对 `update_stamp` 参数的兼容归一化与校验测试；
- **工作台主站切换交互与文案优化**：
  - 彻底清除切换主站和拖拽保存确认弹窗中残留的废弃“关闭定时排片”描述；
  - 弹窗标题重构为明确的目标主站提醒（`主站改为「XXX」？`），并在副标题清晰展示操作影响（`将清空当前轮播卡组与排片配置。`）；
  - 同步清理数据重置面板及底层服务代码注释中的陈旧定时排片描述；
- **多端子模块同步与播放器优化**：
  - 同步更新 Android 端子模块 (`app-for-android`) 至 v1.1.0，优化弹幕图层与播放器生命周期；
  - 同步更新鸿蒙端子模块 (`app-for-ohos`)，优化全屏转场与播放器手势联动。
