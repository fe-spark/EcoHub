预发布版 **v3.0.0-beta.7**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.7`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.7`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.7 核心变更

- **计划任务精简重构与状态闭环**：废弃多余的定时排片与死重任务关联表，计划任务类型重构收拢为连续纯数字序列 `0 ~ 4`（自动采集、失败重试、片库清理、日志清理、记录清理）；失败记录物理清理保留期严格对齐为 7 天。
- **定时采集复用批量采集核心链路**：移除原定时采集特有的备用站哈希错峰与逐站 5~15 秒休眠延时逻辑，定时采集完全复用采集中心的批量采集入口，多站并发启动，生命周期完全一致。
- **采集队列“收尾中”检索索引数字进度**：采集队列在全部站点拉页入库完成后，平滑进入“收尾中”状态，就地承接全站检索倒排索引重建与封口，实时通过 SSE 展示扫描与加载进度，索引封口完毕即刻标记完成。
- **首选站切换解耦**：移除旧版本首选站变更与定时排片的强耦合，切换主站后自动确保默认排片规则就绪，杜绝轮播管理异常。
