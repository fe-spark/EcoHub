正式版，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.4.1` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **从 v2.4.0 升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。
- **数据库**：启动时 GORM 会为访问分析日汇总表自动增加走势字段，无需手工迁移。

---

### 核心变更

#### 1. 访问分析：按日切换数据对齐

- **历史日走势**：日汇总落库时写入 15 分钟走势；已归档但缺少走势的日期，若 Redis 分钟桶仍在会自动补回，避免切到昨天只看到「暂无走势数据」。
- **排行与日志**：热门点播 / 热搜优先读当天排行表，空则回退 Redis；访问日志按所选日期过滤，当天桶为空时从全局最近列表再筛。
- **切日不再串数据**：切换日期会先清空当前看板再加载，并显示加载态，避免日期已变、数字仍是上一天。
- **今日自动刷新**：仅「今天」支持自动刷新；后台轮询失败保留上一份成功数据，切走标签页会暂停，回到页面立即刷新。

#### 2. 通知设置：关闭推送不再冲掉配置

- 关闭「启用 Telegram 消息推送」后，Bot Token、Chat ID、策略、免打扰与事件订阅仍保留在页面上，保存时与已有配置合并，避免只提交总开关把其余项清空。
- 夜间免打扰改为 `HH:mm` 时间选择器，开启时校验格式。
- 通知页布局整理：总开关置顶，渠道、策略、事件订阅分区展示，并支持事件全选 / 恢复默认。

#### 3. 工作台与数据重置文案

- 工作台与数据重置页不再展示「列表快照」体量；引导与告警文案改为采集收尾入库，与当前主路径一致。
