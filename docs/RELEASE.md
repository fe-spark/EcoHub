测试版 **v2.6.0-beta.6**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.6.0-beta.6`。

### 升级指引

- **从已有版本升级**：
  - **1Panel / Compose**：执行 `docker compose pull ecohub && docker compose up -d ecohub` 即可（或后台「检查更新」一键平滑升级）。
  - **数据结构与兼容性**：完全向下兼容现有 MySQL 与 Redis 数据结构，无破坏性变更。

---

### v2.6.0-beta.6 核心变更

#### 1. 运行时状态改为内存权威
- 影片列表活跃快照版本、主站切换保护期、孤儿播放列表游标改为进程内存读写，Redis 仅在启动时恢复、写入时备忘；
- Telegram Bot 轮询去掉 Redis 领导锁，由本进程直接长轮询；访问分析日滚动与清理去掉 Redis 集群锁，仅用进程内互斥；
- 启动时从 Redis 备忘恢复保护期、孤儿游标与活跃快照版本后再挂定时任务。

#### 2. 通知分类计划排序不再覆盖批次影片列表
- `BuildCategoryPlanForMids` 按更新时间重排入参切片时，不再把重排结果写回批次 `Films`，摘要明细保持原始批次顺序。

#### 3. 部署与文档整理
- 部署指南删除多节点 / Nginx 集群负载均衡示例；
- 移除过期的数据分析重构方案文档。

#### 4. 质量与回归验证
- **全仓测试**：Go 后端相关模块单元测试通过（含快照版本、主站切换保护、孤儿游标、访问分析清理与通知批次会话）；
- **前端检查**：本次无前端逻辑变更。
