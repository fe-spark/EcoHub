测试版 **v3.0.2-beta.7**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.2-beta.7`。

### 升级指引

- **从 v3.0.x 升级**：`docker compose pull ecohub && docker compose up -d ecohub`。
- **v2.x**：不兼容，不迁移。必须全新目录部署，勿挂载旧库。

### v3.0.2-beta.7 变更

- 修复全量采集后前台搜索遗漏缺陷：彻底移除 1500 条人为硬截断，流式刷窗按需分批封口进倒排索引，全量采集收尾触发全库扫描校准，确保主站影片 100% 具备即时检索能力。
- 批次影片清单弹窗重构：默认 10 条/页紧凑展示，左侧配备显式「搜索」与「重置」按钮（拒绝隐式回车），右侧直达影片库，去除局部固定高度与滚动条限制。
- 入库影片独立全量落库与异步检索：新建 `collect_record_films` 表，采集入库影片全量落库并按站点/批次去重；明细抽屉新增影片清单弹窗，支持按站点、片名关键字分页检索并直达播放页，存量旧记录自动降级标注为历史样例。
- 采集批次成败以实际产出判定：彻底解决有成功产出被误判为采集失败的问题；单站/多站有成功页又有失败页判定为部分失败，零成功页才判定为采集失败；用户主动停止保持已终止，不再被停止前的失败页翻成部分失败。
- 采集失败与进度信息精准化：单页失败信息附带具体失败页码；站点探页阶段失败明确展示为探测失败，避免 0/0 歧义展示，批次失败不再误显全部完成。
- 数据安全配置备份架构优化：配置导出与导入彻底剔除内置计划任务，旧备份导入直接静默忽略废弃模块，杜绝系统内置守护任务被外部 JSON 抹除或篡改。
- 删站级联清理与启动初始化治理：删除采集源时级联清理该站的批次影片清单与统计；默认采集源仅在全新数据库初始化时写入，用户删源后重启服务不再被强制写入默认站点。
- 重试体验与前端构建加固：重试按钮对部分失败和采集失败批次均可触发；修复抽屉组件 Hook 调用规范并完善异常站点播放线路上下文。
