预发布版 **v3.0.0-beta.12**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.12`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.12`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.12 核心变更

- **分类全站停用与搜索/详情全链路协同拦截**：
  - 分类停用开关升级为全站可见性拦截，内存倒排索引检索（Web/App/TVBox 全端）对已停用分类影视直接在匹配阶段剪枝过滤，搜索不再露出停用分类；
  - 播放详情与相关推荐接入分类可见性校验，访问已停用分类影视直接返回明确下架提示，杜绝隐式降级与静默兜底播放；
  - 采集建档与多源补源对已停用分类智能跳过，避免为下架影视空耗爬虫并发与写库 I/O；
  - 保留已入库影片档案与刮削资产，重新启用分类全站秒级恢复，彻底废除“隐藏分类必须手动删片”的妥协。
- **管理后台安全加固与超级管理员权限边界收敛**：
  - 系统配置、首页轮播、分类规则、计划任务、爬虫采集与 TMDB 刮削等 30+ 项管理接口全面强制接入超级管理员鉴权；
  - 用户个人资料独立自服务接口（锁定当前登录 UID，禁止越权篡改角色或状态），默认内置超级管理员（ID 10000）禁止篡改密码或被禁用；
  - 图库素材重命名与删除接口严格执行所有权校验，非管理员仅可操作自身上传资源；
  - TMDB 配置、采集订阅等接口针对非管理员自动脱敏密钥。
- **采集中心与新手引导交互闭环优化**：
  - 批量操作（批量启用/禁用）完成后保留勾选状态，消除重复勾选摩擦，解决批量启用后无法直接点击批量采集的问题；
  - 新手引导 Tour 弹层层级、遮罩与箭头对齐精准化，解决抽屉展开时提示遮挡与视口溢出问题。
- **后台侧边栏分组菜单默认折叠**：
  - 侧边栏子菜单分组默认全部折叠收起，移除启动全展开设定；进入具体页面时仅激活展开当前归属父项，保持后台清爽干练。
