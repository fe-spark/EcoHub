正式版 **v3.0.0**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0` 及 `latest`。

### 升级指引

- **体验本版**：执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级，建议全新部署。

---

### v3.0.0 核心更新概览

#### 1. 片库与采集中心架构重构
- **各采集源独立建档与首选站聚合**：影片按源物理隔离独立建档，前台与 TVBox 默认基于首选站聚合，彻底消除历史跨站混淆；
- **自适应动态流控与高性能采集**：自适应动态流控、任务终态真实收敛（移除非阻塞状态假死）、异步流式 SSE 进度全链路推送；
- **采集失败记录治理**：成功记录即时清除，最终失败保留 7 天，支持单片/单站精准重试与任务占用锁自愈。

#### 2. 内存倒排检索与极速索引
- **纯内存倒排与增量封口优化**：废除全量库扫描，增量索引局部追加变动影片，封口耗时降至毫秒级，彻底根治大片库 OOM SIGKILL；
- **分类筛选与首页性能治理**：多维标签筛选与排序（最近更新/人气/评分/年份）走高性能内存索引，首页接口分类推荐流熔断截断。

#### 3. 轮播排片与工作台体验升级
- **首页轮播重构为纯手动与一键排片**：支持多分类配额、拖拽排序、批量 TMDB 刮削与审核抽屉；
- **排片策略与分类页严格对齐**：排片策略文案统一为「最近更新」，底层排序与 `/category/filter` 逻辑一致（`update_stamp DESC, mid DESC`），支持 `update_stamp` 兼容映射；
- **工作台主站切换交互优化**：主站切换与排序弹窗明确展示目标站与清空影响，清理废弃的“关闭定时排片”陈旧字样。

#### 4. 安全、权限与多端生态
- **三级角色权限体系**：重构超级管理员/管理员/操作员权限与鉴权中间件；
- **TVBox 接口与数据安全**：分类安全拦截加固、改密盐值刷新与数据备份治理；
- **多端移动端同步更新**：同步升级 Android（v1.1.0）及 HarmonyOS 移动端子模块（弹幕图层防撞、播放器转场与全生命周期优化）。
