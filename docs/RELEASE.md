正式版 **v3.0.2**，镜像 `ghcr.io/fe-spark/ecohub:v3.0.2`（`:latest` 同步指向它）。镜像 tag 见 [部署指南](./README-Deploy.md)。

### 升级

- v3.0.x：`ecohub` 安装的执行 `ecohub update`。1Panel 或自建 compose 在安装目录执行 `docker compose pull && docker compose up -d`。
- v2.x：不兼容，不迁移。见 [从 v2 升级到 v3](./v2-to-v3.md)。

### v3.0.2 修复

- **孤儿数据清理**：改为按 mid 分批删除并逐批上报错误，不再因长事务触发 invalid connection 告警。
- **定时任务加固**：维护任务优先并串行排队，排队中禁用立即执行；过期采集记录分批清理；定时任务与采集协程 panic 会兜底并告警。
- **数据库连接**：健康检查不再替换全局 MySQL/Redis 连接，消除数据竞争；MySQL 建连和 Ping 加 10 秒超时。
- **停止后重试**：一键终止或单站停止后立即重试，旧批次不再改掉新重试的进度、占用或状态。
- **限流续采**：站点有成功页后连续失败 20 页，暂停 5 分钟再从断点继续；连续暂停 3 次仍失败则结束本轮，其他站不受影响。
- **失败页**：不再只记前 500 页，重试失败页可以全部补回。`collect_records.detail_json` 改为 MEDIUMTEXT，启动时自动加宽。
- **采集进度提示**：悬浮显示的失败页按页码排序、连续页合并成区间，内容过长时可滚动。

### 架构

- 取消主从绑定。各采集站独立建档，单站异常不影响其他站。
- 启用站里排序第一的是前台主站。切换立刻换成该站已有数据，不重采、不删片；轮播按站点分开存，首页展示新主站自己那组。
- 播放页按匹配键附上其他站线路：豆瓣 ID + 片名，片名#分类，纯片名。线路按站分开，不合并档案。
- 结构迁移只留空基线，新变更只在末尾追加。

### 采集

- 去掉请求间隔和写库令牌桶。全局在途 128，单站 16 个协程，单页写事务 30 秒超时。
- 零成功且取页失败达阈值才熔断。已有成功页的站连续失败 20 页暂停 5 分钟续采，连续暂停 3 次仍失败结束本轮。停止或导入时丢掉未开写的页，写完已经打开的事务。
- JSON 探页用 `detail`，XML 探页用 `videolist`，与正式抓页一致。
- 定时采集碰到维护会让行，之后按未采窗口补，最多 7 天。只有定时整次成功才移动补窗锚点。规则见 [计划任务冲突](./cron-task-conflict.md)。
- 批次记在 `collect_records`，入库明细记在 `collect_record_films`。状态按实际落库：成功、部分成功、失败、已停止、异常中断。没抓的页写明未抓。
- 30 分钟内重试失败页，超时则整站重采。成功批次归档，历史记录定时清理。
- 未映射影片归入该站一级「其他」（源站「其它」视为同一类）。隐藏或停用的分类（含「其他」）仍正常采集入库，前台不展示。有成功页仍进入待检索；零成功直接失败。
- 封口期间不能删站，也不能改地址或协议。删站只等一次检索收尾。
- 可用内存不超过 2GiB 时，只收紧页并发、取数在途和写队列。

### 检索与前台

- 内存倒排（分词、全拼、简拼）和分类榜。采集增量更新，全库重建只在启动时做。
- 首页隐藏没有影片的分类，分类区块最多 12 个一级分类。导航、筛选和 TVBox 仍用该站全部分类。
- 分类规则按站生效。前台分类的排序和显示跟随管理端映射。隐藏分类（含规则合并组）从前台所有接口消失，旧地址显示分类已失效；搜索、每日更新和 TVBox 关键词也不返回这些片子。采集仍把这些片子入库。分类管理仍可看到并重新打开。子类不会自己变成一级。
- 未映射片子出现在该站「其他」。源站改名占用旧「其他」编号时，兜底换新编号。
- 播放器支持多线路、进度记忆和弹幕。更换弹幕源后不命中旧缓存。
- **图片加速**：开启媒体反代时，前台与 TVBox 海报自动走边缘 CDN，免代理直开且不消耗自建带宽。

### 后台

- 操作改为抽屉。配置、站点和规则可备份导入，导入前会停采集。
- **轮播**：按站点存储，片名、分类、备注等跟随片库实时组装；该站已无播放线路的影片首页不展示，后台标为已失效，可删除和排序。手动增删改排序有版本号校验，并发修改会提示刷新。
- **一键排片**：选策略（最新、最热、高分）和各分类数量，每个分类最多 5 部，不限总数；结果在抽屉里预览、调整后整组发布。排片配置不入库，每次一键排片都弹窗确认，默认最热、每类 1 部；同一页面内再次排片沿用该站上次的选择，刷新后回到默认。
- 分类管理与前台共用同一套规则树，只调整排序和显示。父级隐藏时子类开关不可改。
- 角色为超级管理员、管理员、普通用户。
- 影片列表的 ID 列是源站编号。采集中的失败页只把失败数标红。
- 单条坏线路只跳过该线路。配置已经落库后，缓存写失败会删掉旧值。
- **媒体反代**：支持边缘反代模板配置与校验，服务端出站动态替换海报地址，不污染原数据。
