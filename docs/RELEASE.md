预发布版 **v3.0.0-beta.9**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.9`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.9`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.9 核心变更

- **小内存设备采集后不再整库重读检索索引**：采集结束只刷新这次改过的影片，排行和倒排用内存里已有的全表重算，不再把几十万行再扫进内存。没有现成索引时才全量重建，重建期间仍读旧索引。
