预发布版 **v3.0.0-beta.1**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.1`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.1`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据**！旧版数据结构已被彻底废弃推翻，请勿直接挂载 v2.x 历史数据库升级；建议全新部署或清空旧数据库后启动并重新配置采集站。

---

### v3.0.0-beta.1 核心变更

- **终止采集状态与上次运行信息闭环**：修复终止队列或单站停止采集后卡片丢失上次采集页与时间的问题，覆盖 `done`、`stopped`、`failed` 全终态流式推送与数据库实时落盘，0 页正常结束或中途终止均完整记录。
- **采集站异步级联删除与实时进度**：删除采集站接入后台异步队列与 SSE 实时广播，顶部实时显示级联删除进度条与实际删除影片总数，提交失败即时拦截防假死。
- **纯净本地数据重置**：数据重置彻底零外网 HTTP 请求依赖，物理清空片库业务数据同时完整保留本地分类库与映射字典，解决因外部采集站失效或 403 导致重置中断的问题。
- **首选站切换平滑化与并发防抖**：首选站变更引入 150ms 防抖、递增世代（Epoch）校验与倒排索引重建排他锁，彻底杜绝拖拽排序高频全表扫描及缓存覆写。
- **分类排行榜隔离加固与容错兜底**：修复分类排行榜在特定源无数据时的跨源泄露隐患；前台分类专区参数缺失或异常时自动识别并兜底首个有效大类。
