测试版 **v3.0.2-beta.3**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.2-beta.3`。

### 升级指引

- **从 v3.0.x 升级**：`docker compose pull ecohub && docker compose up -d ecohub`。
- **v2.x**：不兼容，不迁移。必须全新目录部署，勿挂载旧库。

### v3.0.2-beta.3 变更

- 采集运行改为批次记录：彻底废除旧失败记录与页级重试，全量/定时/单站/单片统一按批次管理，失败站点支持就地重试与异常熔断自愈。
- 单片更新按原影片重放：开工前先行写入运行中记录，成功且无变更时明确标注，片名标签支持直达前台播放页。
- 采集记录体验革新：废除繁重嵌套表格，改用侧边成果明细抽屉；细化展示各采集站入库影片清单并直达前台播放；筛选栏精简为一键分段快捷切换（全部 / 有入库 / 有失败 / 执行中）。
- 定时清理与维护升级：定时任务自动改为清理超过 30 天的采集运行记录，启动阶段自动修复历史异常中断批次。
- 修复采集记录页类型检查：异常站点原因列参数定义对齐，保障前端生产构建稳定。
