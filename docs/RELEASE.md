正式版 **v2.7.0**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.7.0` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **平滑升级**：支持后台「检查更新」一键平滑升级，或通过 `docker compose pull ecohub && docker compose up -d ecohub` 快速拉取新镜像。
- **数据库自迁移**：启动时自动执行每日更新复合覆盖索引迁移与补丁更新，无需手动干预。

---

### v2.7.0 核心变更

- **服务端架构深度重构**：
  - 全面拆解仓储层（`snapshot` / `writer` / `shared` / `poster` / `query`）与采集层（`fetcher` / `progress` / `scheduler` / `converter`）子包架构，严格践行高内聚低耦合与模块单一职责。
  - 日志目录上溯至模块根目录，测试环境深度净化，消除单测对运行环境的副作用。
- **同名跨类智能打分与精准隔离**：
  - 建立同名跨类按豆瓣/名称/类别/标签/年份/备注形态综合打分绑定机制，彻底杜绝多站错源与串源。
  - 错槽精准清理机制，仅清理同一部影片误写到他人独占键上的历史旧行，保障多数据源严格一致。
- **高可用性能优化与缓存闭环**：
  - 每日更新接口建立 `(update_stamp, mid)` 与 `(pid, update_stamp, mid)` 复合覆盖索引，消除全表 Filesort 文件排序。
  - 每日更新统计与分页接入短缓存与 Singleflight 防击穿防穿透保护。
  - 读模型快照发布、主站切换、数据重置全链路闭环淘汰每日更新、影片详情、筛选列表及 TVBox 缓存。
  - 数据重置闭环：重置时连带清空关联影片的轮播图与采集失败记录，彻底杜绝首页死链与孤儿数据。
- **私有化访问安全控制体系**：
  - 支持私有化访问控制：开启时自动生成 16 位高强度安全随机密钥，支持管理后台一键重新生成与持久化兜底保护。
  - 重构拦截响应码与状态反馈（精准区分放行、403 密钥错误、401 需鉴权），解决客户端接入鉴权困惑。
- **接口与终端订阅规范化（`/api/provide/{终端}`）**：
  - 软件源配置统一支持单地址栏直接解析填入（私有化源末尾追加 `?key=...`），移除冗余输入项与过时说明。
  - 工作台订阅地址弹窗精准联动私有化开关：仅在开启私有化访问时自动拼接专属密钥参数，公开站点保持纯净端点路径。
- **网站系统配置模块化解耦**：
  - 网站配置重构为【网站基本信息】与【运行与访问控制】同页独立配置卡片，独立保存互不干扰。
  - 访问控制接口与基本配置接口针对访客角色实施密钥脱敏，杜绝安全越权隐患。
- **客户端与前端体验优化**：
  - 修复无轮播 Banner 时顶部分类胶囊与 Header 重叠的排版问题，自适应顶部状态栏与安全区避让。
  - 修复标签筛选 others 条件被忽略返回全量数据的缺陷。
  - 管理端工作台新增采集队列实时进度展示。
  - 联动更新鸿蒙原生客户端 `app-for-ohos`（v1.4.0）：单地址栏解析、私有化订阅鉴权对齐、独立关于页与视觉基准重构。
