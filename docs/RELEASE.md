正式版 **v2.6.4**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.6.4` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **平滑升级**：支持后台「检查更新」一键平滑升级，或通过 `docker compose pull ecohub && docker compose up -d ecohub` 快速更新。
- **数据兼容**：完全向下兼容现有 MySQL 与 Redis 数据结构，无破坏性变更。

---

### v2.6.4 核心变更

#### 1. 数据分析与主站切换历史快照固化
- **历史快照脱耦**：日志写入时固化影片快照，彻底解决修改主站链接或重爬后历史明细退化为「影片 #ID」或片名错位的问题。
- **零查库极速写入**：日志采集链路采用纯内存提取与短路保护，杜绝高并发下通道阻塞与丢日志隐患。
- **快照优先读取**：后台访问明细与统计排行优先展示不可变快照，防止被后续新主站数据覆盖篡改。

#### 2. 播放链接动态域名替换引擎
- **动态规则配置**：支持按采集源配置域名替换规则，播放与下载链接即时生效，轻松应对上游防盗链与线路切换。
- **缓存精准淘汰**：规则变更自动联动淘汰关联播放详情与列表缓存，并修复编辑源时规则意外丢失的问题。

#### 3. TVBox 接口高并发加固
- **SingleFlight 防击穿**：列表页同参数并发请求自动合并，配合双检机制保护数据库。
- **随机 Jitter 防雪崩**：缓存过期时间增加随机扰动，空列表设置 1 分钟短 TTL 防穿透。
- **切片隔离防竞态**：列表输出前显式浅拷贝切片，杜绝多 Host 并发访问时海报地址读写冲突。

#### 4. 基础性能与安全调优
- **容器极速停机**：移除升级时旧容器 20s 慢停机等待，改为非阻塞毫秒级快速退出，实现一键升级秒级切换。
- **连接池扩容**：Redis 连接池容量扩至 64（MinIdle: 10），显著提升高并发吞吐能力。
- **海报安全过滤**：海报 URL 强制校验 HTTP/HTTPS 协议并截断，严密拦截伪协议 XSS 攻击。
