正式版 **v2.7.1**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.7.1` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **平滑升级**：支持后台「检查更新」一键平滑升级，或通过 `docker compose pull ecohub && docker compose up -d ecohub` 快速拉取新镜像。
- **配置持久化**：系统配置、TMDB 刮削凭据与影片元数据持久化存储，平滑升级无需重新初始化。

---

### v2.7.1 核心变更

- **TMDB 影视元数据智能刮削体系**：
  - 全面接入 TMDB 官方 API，支持海报、横版幻灯背景、剧情简介、副标题/原名、演职员阵容、上映年份、TMDB 评分与分类标签一键智能匹配与表单回填。
  - 管理后台新增 TMDB 独立系统配置卡片，支持安全存储 API Key、自定义代理地址与刮削总开关。
  - 智能感知配置状态：未开启或未配置 TMDB 凭据时，自动静默收起智能识别与刮削按钮，保持界面清爽。
- **线路形态硬冲突阻断与防串源机制**：
  - 建立线路形态（剧集 / 电影 / 短剧 / 动漫 / 综艺）与身份识别强约束机制，彻底杜绝同名跨体裁、短剧错混入同名正统剧集的串源问题。
  - 增强主从线路形态校验与快照隔离，保障多源采集入库的数据绝对纯净。
- **影视编辑保存性能优化与交互升级**：
  - 深度优化影视信息编辑保存性能瓶颈，隔离基础信息与海量播放资源的分级更新。
  - 大幅缩短影视修改保存响应耗时，重构基础信息排版布局并支持 TMDB 字段还原。
- **片库选片弹窗（FilmPicker）全面体验重构**：
  - 修复检索中因空状态高度坍缩导致的 Loading 动画被顶部排序栏截断与遮挡缺陷。
  - 规范化桌面端管理体验：重构为一体化检索工具栏（原生紧凑搜索框 + 分段排序控制器）。
  - 优化海报卡片流排版、悬浮微动效、已选定高亮反馈，并支持双击卡片直接确认选择。
