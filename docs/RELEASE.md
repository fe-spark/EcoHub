正式版 **v2.5.4**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.5.4` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **从已有版本升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。
- **兼容性说明**：本版本完全向下兼容现有 MySQL 与 Redis 数据结构，无破坏性变更。

---

### v2.5.4 核心变更

#### 1. Telegram 通知摘要体验精简与优化
- **智能隐藏成功源明细**：采集批次摘要默认隐藏全部正常的采集源列表，彻底解决源过多时的刷屏问题，无论配置多少个源，摘要消息均保持简洁短小。
- **异常失败源精准呈现**：仅在采集批次中存在失败源时，紧凑输出 `❌ 源名称（主站/附属）：错误原因`，便于管理员即时排查故障。
- **指标与排版自然化重构**：移除生硬的 `✅ / ❌` 符号堆砌，独立拆分 `🎬 采集数量：更新 X 部` 统计行，文案结构清晰易读。
