预发布版 **v3.0.0-beta.14**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.14`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.14`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.14 核心变更

- **三级角色权限体系彻底重构（运营权回归）**：
  - 彻底解开此前过度收紧的一刀切拦截，恢复 **普通用户（`role=0`）** 完整的日常业务运营权限（影视录入/修改/删除、TMDB 刮削与应用、首页轮播排片、分类映射规则、采集日常启停与失败重试）；
  - **超级管理员（`role=1`）** 严格收敛并独占系统级防线（系统核心配置、网络代理/通知敏感密钥、全站账号管理、全库清空与历史流水销毁、应用升级、配置导入导出）；
  - **访客用户（`role=2`）** 统一在网关层由 `WriteAccess` 拦截所有写请求，保留纯只读审计定位。
- **开放普通用户访问数据分析大盘**：
  - 数据分析（`/manage/access`）解除超管独占，普通用户正常享有流量概览、访问趋势图与热门影片排行榜查看权，助力日常选片与运营。
- **清理历史兼容补丁与代码死重**：
  - 彻底剔除分类表开机运行时探测与 `DropIndex` 历史兼容补丁，交由模型结构体统一声明；
  - 移除废弃常量 `MAX_NOTICE_VERSION_LEN` 与下线端点的遗留注释；
  - 简化分类 ID 转换，去除跨库自增 ID 飘移的两道冗余 SQL 查询。
- **超管账号初始性别规范化**：
  - 内置超级管理员账号（UID 10000）初始化默认性别彻底规范为 **保密（`0`）**，移除历史硬编码默认值。
