测试版 **v2.1.2-beta.3**，镜像 `ghcr.io/fe-spark/ecohub:v2.1.2-beta.3`，**不会**覆盖 `:latest`。

已部署 **v2.1.0** 及以上：把 compose 镜像改成 `ghcr.io/fe-spark/ecohub:v2.1.2-beta.3` 后执行 `docker compose pull && docker compose up -d`。正式版后台不会把 beta 当作可升级版本。

从 **v2.1.0 之前** 升级的，请先按 [v2.1.0 说明](https://github.com/fe-spark/EcoHub/releases/tag/v2.1.0) 做完素材卷迁移，再升到本版本。

### 本版本变更

- 定时增量采集按源补窗：主站中断超过默认 3 小时后，下次定时按「距上次成功时间」加长窗口（上限 7 天）；手动采集仍用所选时长
- 停止 / 失败 / 与同站任务撞车时不刷新「上次成功」时间，避免补窗被截断
- 「最近更新」仅当本源集数第一次超过全库已有最大集数时上榜；后到的源追到同一集数、只改最后一集标签不再重进列表
- 首页轮播按后台配置条数展示，不再用片库凑满；更新状态与最近更新同源（全库最大集数）
- 后台轮播去掉手填「更新状态」
