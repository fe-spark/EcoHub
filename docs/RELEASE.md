预发布版 **v3.0.0-beta.15**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.15`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.15`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.15 核心变更

- **采集队列终止与进度闭环优化**：
  - 手动终止采集队列接入严格的全量终态监视器，严格确保队列内所有站点无一例外全部退出并落地终态后，才平滑切换为「采集已终止」通知；
  - 队列停止成功后即时清空卡片进度，杜绝提示已消失但卡片仍卡在「停止中」进度条的体验瑕疵；
  - 彻底清理遗留常驻 loading 状态，消除重新批量采集时被旧提示遮挡的问题。
- **三级角色权限体系重构与运营权回归**：
  - 恢复普通用户完整的日常业务运营权限（影视增删改、TMDB 刮削与应用、首页轮播排片、分类映射规则、采集日常启停与失败重试）；
  - 超管独占系统核心配置与敏感凭据防线；访客全量写拦截保持纯只读。
- **开放普通用户访问数据分析大盘**：
  - 解除超管独占，普通用户正常享有流量概览、访问趋势图与热门影片排行榜查看权。
- **清理历史兼容补丁与代码死重**：
  - 剔除分类表开机运行时探测与 `DropIndex` 历史兼容补丁；移除废弃常量与已下线端点残留注释；简化分类 ID 转换。
- **超管账号初始性别规范化**：
  - 内置超级管理员账号（UID 10000）初始化默认性别彻底规范为 **保密（`0`）**。
