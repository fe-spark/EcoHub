预发布版 **v2.5.5-beta.0**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.5.5-beta.0`。

### 升级指引

- **从已有版本升级**：执行 `docker compose pull && docker compose up -d` 即可（或后台「检查更新」一键平滑升级）。
- **兼容性说明**：本版本完全向下兼容现有 MySQL 与 Redis 数据结构，无破坏性变更。

---

### v2.5.5-beta.0 核心变更

#### 1. 数据分析与流转看板全新重构
- **多端业务看板**：新增 Web 独立视图、App 移动端独立视图（支持 Android/HarmonyOS/iOS 切换过滤）与 TVBox 大屏专属视图，支持分端洞察流量、PV/UV、渠道版本与流转日志。
- **全量排行榜查看**：“热门点播”与“热门搜索”卡片右上角新增“查看全部”入口，支持模糊搜索、动态分页（10/20/50/100 条）与换页平滑回滚，彻底解除 Redis 200 条硬截断限制，完整保留单日全量点播与长尾搜索记录。
- **设备身份精准追踪**：鸿蒙端支持自动提取商业机型（如 `HUAWEI Mate 60 Pro`）并沙箱持久化唯一设备 ID，流转日志告别空数据 `-`。

#### 2. 系统与接口调用分析完善
- **接口调用分析**：独立管理端日志，支持高频调用、慢请求分析与错误排查。
