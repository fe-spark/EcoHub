正式版 **v2.7.9**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.7.9` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **平滑升级**：后台「检查更新」一键升级，或执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **数据兼容**：全自动平滑升级，无需手动执行 SQL 或重新初始化配置。

---

### v2.7.9 核心变更

- **影片列表与采集源隔离**：后台影视列表严格展示所选采集源对应数据，切换源站实时联动刷新该源专属分类树，选择分类即时触发列表筛选。
- **分类层级与搜索范围控制**：后台与检索支持选中一级大类（自动覆盖自身及下属全部二级子类）与选中二级分类精准过滤，彻底杜绝规则聚合分类跨类串联问题。
- **前台展示对齐首个基准源**：前台首页、分类专区与片库检索默认全链路严格对齐采集中心首个启用源（基准源），绝不混杂展示其他源站数据。
- **分类同步**：源站已给出层级时保持原父子关系，不再按名称改挂。修复新增或切换主站后分类保存失败、前台分类为空的问题。
- **账号**：初始化只创建超级管理员。超级用户可新建超级用户、普通用户或访客，并可修改账号状态。邮箱默认留空。
- **访客**：后台只读，分类管理不能保存。
- **编辑账号**：弹窗打开后再回填，避免用户名为空导致无法保存。
