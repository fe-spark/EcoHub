预发布版 **v3.0.0-beta.3**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.3`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.3`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据**！旧版数据结构已被彻底废弃推翻，请勿直接挂载 v2.x 历史数据库升级；建议全新部署或清空旧数据库后启动并重新配置采集站。

---

### v3.0.0-beta.3 核心变更

- **播放器弹幕**：支持本站弹幕发送与按进度展示。Seek 后按当前时间重排在途弹幕，全屏与窗口使用不同飞行时长。后台可开关弹幕，并配置弹弹play 嗅探与 AppId；非管理员接口不返回密钥。保存站点信息时，未带弹幕对象或密钥留空不会清空已存配置。
- **检索倒排增量重建**：影片改名或增量更新后按当前片库重建倒排，避免多字检索漏结果。
- **采集失败收口**：总页探测失败会标成 failed 并释放占用，不再卡在 starting。失败页重试不再把上一轮停止状态当成这次停止；取消中的重试不扣重试次数。
- **首页分类**：首页展示尚无影片的分类，并移除废弃的 live play 路由。
- **播放器边框**：边框改到外层容器，圆角不再裁掉底边和右边。
