测试版 **v3.0.0-beta.1**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.1`。

### 升级指引

- **从 v3.0.x 升级**：`docker compose pull ecohub && docker compose up -d ecohub`。
- **v2.x**：不兼容，不迁移。必须全新目录部署，勿挂载旧库。

### v3.0.0-beta.1 变更

- 采集全速调度重构：移除采集源间隔字段与写库令牌限制，网络请求平时零延迟直通并设 429 静态冷却，单站采用固定页并发与单页写事务 30 秒超时控制。
- 容错停站与停止加速：单站零成功页且取页失败达到上限才停止站点；手动停止与配置导入立即丢弃未开写页面，各个停止路径明确记录具体停止原因。
- 计划任务让行与补窗：定时采集与系统维护冲突时采集直接让行并跳过本轮，后续自动按实际窗口补窗采集。
- 采集记录与片单治理：单站与批量采集统一接入批次上下文，入库影片清单全量读取 `collect_record_films` 表，清理历史抽样片单与冗余触发标签。
- 搜索索引与探页优化：增量更新同步刷新热度、年份与多源榜单，影片重命名时重构倒排索引，变动超两万条触发全量重建；XML 探页默认使用轻量 `ac=list`。
- 数据库基线治理：清理历史补丁与过时结构，版本迁移保留空基线作为后续演进模板。
