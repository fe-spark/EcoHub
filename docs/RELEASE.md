预发布版 **v3.0.0-beta.13**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.13`。不会覆盖 `latest`。

### 升级指引

- **试用本版**：把 Compose 镜像版本指定为 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.13`，然后执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **破坏性变更与数据兼容**：**不兼容，不迁移。** 本版本为 v3.0 重大架构重构版本，完全不向后兼容 v2.x 历史数据。已入库的播放列表也不会改写；重复选集要重新采集对应站点才会拆开。请勿直接挂载 v2.x 历史数据库升级。

---

### v3.0.0-beta.13 核心变更

- **TVBox 与软件源接口分类拦截加固**：
  - `/api/provide/vod` 播放详情与列表深度协同全站可见性拦截，对已下架停用分类影视直接阻断播放流与聚合线路，彻底修复通过接口反查获取下架影片播放地址的隐患；
  - 列表检索加入全局停用分类排除条件与内存标签二次过滤，多端一致性对齐。
- **个人资料改密安全校验与密码盐值刷新**：
  - `/manage/user/profile` 改密接入当前密码强制二次校验，防御会话劫持风险；
  - 密码修改重构为强制生成全新随机盐，废弃旧盐复用，并同步持久化。
- **素材批量删除原子预检与分类大页防护**：
  - 素材批量删除前全量校验存在性与所有权，杜绝部分删除导致的数据不一致；
  - 分类聚合板块展示页与标签筛选接入分类停用拦截，无残留露出。
- **客户端子模块同步**：
  - Android 与 HarmonyOS 客户端子模块同步最新提交，完善播放埋点采集站上报。
- **影片管理抽屉多线路协同与播放直链动态联动**：
  - 修复影片编辑抽屉在同一来源或多个线路间切换时，播放直链输入框未跟随选中线路联动刷新的问题；
  - 接入各线路独立直链缓存与编辑状态隔离，支持所属源多线路整体合并保存（`$$$` 分隔），杜绝保存时非激活线路被意外剔除。
- **账号管理抽屉用户名校验优化**：
  - 修复编辑现有账号时对已锁定禁用的用户名做必填校验导致保存阻断的问题；
  - 优化兼容各源端用户名取值与后端 ID 解析，保证编辑场景平滑提交。
