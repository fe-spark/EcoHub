测试版（Pre-release），Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.5.0-beta.15`。

### 核心变更

#### 1. 首页轮播海报与元数据实时联动
- **后端快照动态注入**：扩展 `Banner` 响应模型，通过 `LiveBannerSnapshotsByMIDs` 从只读快照中批量动态回填地区、类型、主演、导演、简介、评分与热度字段，实现全站轮播海报与片库快照实时同步。
- **前台焦点图交互升级**：重构 `HomeHero` 组件，新增画质标签（4K/1080P/HD/720P）智能识别、精选推荐徽标、分类标签提取与响应式动态剧情简介。

#### 2. 管理后台轮播排片模块重构与通用片库选择器
- **组件结构解耦**：将原本 750+ 行单文件重构解耦为 `index.tsx`（列表页）、`banner-modal.tsx`（编辑弹窗）、`types.ts`（类型定义），严格遵循单文件 ≤ 500 行规范。
- **全站片库选择器 `FilmPicker`**：新增全站通用片库选择组件，支持片名/主演模糊搜索、综合/热度/评分/年份多维排序、卡片即时图文预览与双击快捷选定。
- **精准回显机制**：轮播编辑支持根据 `mid` 调用 `filmPlayInfo` 精确回显影片详情。

#### 3. UI 体验与深色主题适配优化
- **状态渲染修复**：修复影视新增页面 `loadedDetailRef` 未触发 React 重新渲染导致海报无法即时展示的问题。
- **移动端排版优化**：优化移动端卡片标签展示规则，移动端窄卡片上限保留前 2 项核心标签防止截断。
- **主题细节微调**：优化管理后台深色模式下表格单元格背景色与组件库图标选中态。
