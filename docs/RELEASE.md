正式版 **v2.7.7**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.7.7` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **平滑升级**：后台「检查更新」一键升级，或执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **数据兼容**：全自动平滑升级，无需手动执行 SQL 或重新初始化配置。

---

### v2.7.7 核心变更

- **XML 格式采集**：支持苹果 CMS XML 格式采集，兼容 GBK 与 UTF-8 编码。
- **主站保护治理**：禁止直接删除或降级主站，支持将附属站提升为主站并自动置换。
- **分类语义映射**：优化语义化分类层级推断，校准电影与电视剧子类归属。
- **重测代理可选**：采集站测试接口支持重复点击重新选择代理或直连。
- **采集站排序**：按创建时间保序排列，新增采集站自动排在末尾。
