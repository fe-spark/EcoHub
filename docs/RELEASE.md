测试版 **v3.0.0-beta.0**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v3.0.0-beta.0`。

### 升级指引

- **从 v3.0.x 升级**：`docker compose pull ecohub && docker compose up -d ecohub`。
- **v2.x**：不兼容，不迁移。必须全新目录部署，勿挂载旧库。

### v3.0.0-beta.0 变更

- 采集按 CPU 核数分两档：2 核及以下收紧并发，3 核及以上全速。启动时确定，不再手动选档。
- 手动停止和连续 10 次失败都先停掉未取页面，已取到的页写完后再把该站移出队列。连续失败提示在移出队列时出现，文案为「已超出连续失败限制，xxx采集失败」。
- 采集记录与实际写入对齐：失败页只计真正失败的页，没抓的页单独显示为未抓；连续失败记为失败；入库影片包含新片、线路写入和资料更新，内容未变不计入。
- 定时采集若距上次成功较久，记录和重试都使用补齐后的实际小时窗口。
- 运行中分批落下已入库影片。进程中断后，记录标为中断并保留已经落库的影片清单。
- 每批采集结束封口一次搜索索引。变更达到 5 万或有删除时重建内存索引，否则增量更新。索引缺失或读取失败才全库扫描。
- 同一秒内的定时任务合并。维护任务与定时采集落在同一批时，跳过该次定时采集。
