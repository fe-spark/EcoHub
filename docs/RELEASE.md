正式版 **v2.7.3**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.7.3` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **平滑升级**：支持后台「检查更新」一键平滑升级，或通过 `docker compose pull ecohub && docker compose up -d ecohub` 快速拉取新镜像。
- **配置持久化**：系统配置、TMDB 刮削凭据与影片元数据持久化存储，平滑升级无需重新初始化。
- **存量播放源对齐**：若需同步附属站历史数据，可运行 `docker exec -it Eco-hub /app/migrate_slave_playlist_keys --dry-run` 预览迁移，确认无误后去掉 `--dry-run` 执行。

---

### v2.7.3 核心变更

- **首页轮播智能排片与 TMDB 自动刮削**：
  - 排片模式与 TMDB 刮削完全解耦，未配置 TMDB API Key 也能自由开启并运行自动智能排片；
  - 按需 TMDB 刮削：仅对选中的影片并发刮削补齐 16:9 横屏大图，未搜到或无横图自动从片库已有横图影片中顶替兜底；
  - 200 部候选大池 Fisher-Yates 随机打散，全新候选影片全量随机抽取，上一轮在展影片去重轮换；
  - 轮播排片与采集彻底解耦，纳入系统「计划任务」（Model 5）统管；手动模式自动停用锁定，自动模式恢复启用；
  - 自动与手动排片数据结构 100% 对齐，列表统一显示「自定义封面」，支持二次编辑精准回填与分别选图/上传；
  - 按钮尺寸全局统一为中等尺寸（Medium），弹窗动态进度展示并提供 120 秒熔断保护。
- **跨站播放列表精准绑定与迁移优化**：
  - 播放源绑定采用片名精准规范化匹配，消除片尾进度、清晰度、语种等噪音干扰，保留版本标识；
  - 优化迁移工具执行效率，扫描播放列表改走主键批量删除与分批上报进度，支持安全中断与幂等重跑。
