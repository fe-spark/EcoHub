正式版 **v2.7.5**，Docker 镜像 `ghcr.io/fe-spark/ecohub:v2.7.5` 与 `ghcr.io/fe-spark/ecohub:latest`。

### 升级指引

- **平滑升级**：后台「检查更新」一键升级，或执行 `docker compose pull ecohub && docker compose up -d ecohub`。
- **数据兼容**：全自动平滑升级，无需手动执行 SQL 或重新初始化配置。

---

### v2.7.5 核心变更

- **附属站分类防撞车**：清空上游私有分类 ID，严格按规范中文分类名比对大类，根治动漫播放源错挂短剧。
- **多分类均衡配额**：按所选分类数量严格均分排片配额（如 10 选 2 各 5 部），确保各分类展示量对等。
- **Round-Robin 交错排片**：多分类影片交替穿插呈现，彻底杜绝首页大轮播同类别影片连续扎堆。
- **公平轮询与单类止损**：各分类小步轮流并发刮削，根治队头阻塞与后置分类饥饿；设置探测上限，冷门分类适时止损。
- **单次去噪极速刮削**：精简两阶段搜索为一步去噪检索，剥离画质与集数等杂质，TMDB 请求量与刮削延迟直接减半。
- **外部故障快速熔断**：遇到 HTTP 401（Key 失效）、429（限流）或连续网络故障立即熔断并透传真实报错，杜绝死循环空转。
- **移除历史刮削回填**：开启刮削时纯粹依赖本次实时刮削结果，不拿库中历史已有数据兜底混充。
