# 首页轮播智能排片与 TMDB 自动刮削需求说明书

- **版本**: v2.1 (精简同步版)
- **模块**: 首页轮播管理 (`/manage/banners`) 与排片调度引擎
- **生效范围**: EcoHub 服务端、后台管理系统、定时调度器

---

## 1. 核心业务原则

1. **模式解耦**：排片模式（手动/自动）与 TMDB 影视刮削完全解耦。无论系统是否配置 TMDB，均可自由开启并运行【自动智能排片】。
2. **真·按需刮削**：TMDB 刮削作为自动排片下的独立可选子开关。开启时，仅对已选出且缺少横图的影片发起针对性并发刮削；关闭时零网络请求，自动使用竖版海报兜底。
3. **公平轮换去重**：从候选大池（200 部）中全量随机抽取全新影片，上一轮展示影片严格去重归 0；彻底破除“只在历史刮削影片中死循环”的问题。
4. **数据与交互 100% 对齐**：自动排片生成的轮播项与手动模式数据结构完全一致，列表统一展示【自定义封面】，且每行均支持打开弹窗进行二次编辑与回填。
5. **秒级轻量响应**：配置保存即时落库，无阻塞式预刮削；按钮全局统一为 Medium 尺寸。

---

## 2. 详细需求清单

### 2.1 排片模式与 TMDB 刮削解耦
1. **零门槛自由切换**：移除所有阻断自动排片的前端禁用与后端拦截，无 TMDB 也能保存并运行自动排片。
2. **独立可选子开关**：提供【影片是否刮削】（`autoTMDB`）开关。未配置 TMDB API Key 时给出配置指引，不阻断排片；已配置时可自由开启或关闭对排片影片的元数据刮削。
3. **无强制降级**：关闭 TMDB 或清空密钥时，自动排片保留原有运行模式，仅暂停在线刮削并记录日志，绝不强切手动。
4. **轮播数量严格限制**：排片轮播数量区间限制为 **1 ~ 12 部**（默认 6 部），前后端强制截断兜底。
5. **计划任务统管与状态联动**：
   - 首页轮播排片彻底与影视采集解耦（采集完成不再触发排片刷新）；
   - 纳入系统【计划任务】（`sys_cron_banner_auto`，Model 5）统一调度与监控，支持自定义执行周期；
   - 轮播切换为手动精选模式时，计划任务自动停用并置灰锁定提示；切换为自动智能排片时自动恢复启用。

### 2.2 排片算法与轮换去重（核心）
6. **大池打散与严格隔离**：
   - 候选影片池采样 200 部，通过 Fisher-Yates Shuffle 随机打散；
   - 严格隔离为 `freshCandidates`（全新候选）与 `existingCandidates`（当前在展），点击【换一批】时旧片复用数归 0。
7. **公平随机抽取（彻底消除偏差）**：
   - 无论候选影片是否有横图，一律享有均等的抽选概率，从 `freshCandidates` 中按策略随机抽选目标数量；
   - 彻底废除“偏好已有横图”逻辑，解决关闭刮削后老是在历史刮削片里打转的缺陷。
8. **选到谁才刮削谁（真·按需刮削与未命中顶替）**：
   - **开启刮削**：仅针对本次抽中的影片中缺少横图的影片发起并发 TMDB 刮削，补齐 16:9 Backdrop 并写回；
   - **未刮削到横图顶替机制**：若抽中的影片在 TMDB 搜不到或未提供横屏大图，**自动从片库已具备横图的影片中挑选一部进行顶替**，最大化保障前台大轮播高清不模糊；
   - **关闭刮削**：零网络请求，纯随机公平轮换，直接使用竖版海报（`PictureSlide = pic`）优雅兜底，确保排片 100% 成功。
9. **排片策略精简标签**：
   - 下拉选项统一为 4 字极简文案：`热门优先`、`高分精选`、`最新上架`、`智能综合`，详细说明收纳于 `title` 提示中。

### 2.3 数据结构、表格与编辑回填对齐
10. **数据结构 100% 对齐**：
    - 自动排片项字段与手动模式完全一致：`isCustomPic: true`、`customPicture: pic`、`picture: pic`、`poster: pic`、`pictureSlide: slide`。
11. **列表展示与权限对齐**：
    - 封面模式列统一显示【自定义封面】Tag（受锁定保护，采集不覆盖）；
    - 操作列开放【编辑】与【删除】按钮；无横图时展示“无横屏大图”占位。
12. **编辑弹窗精准回填**：
    - 打开编辑弹窗时自动激活【否（自定义封面）】，并回填竖版海报与横屏大图，支持分别选图/上传并保存。

### 2.4 UI 交互与系统工程规范
13. **按钮尺寸统一**：全页面按钮统一采用 Ant Design 中等尺寸（`size="middle"`）。
14. **动态进度反馈**：换一批进度弹窗根据是否开启刮削动态呈现文案（“智能排片与 TMDB 刮削”或“自动智能排片”），配置 120 秒超时熔断。
15. **工程规范**：
    - 单文件行数严格 **≤ 500 行**；
    - 前端统一 CSS Module，**严禁使用 `:global`**；
    - 垂直架构严格遵守 `Handler -> Service -> Repository`；
    - 单行配置表记录使用 `tx.Unscoped().Delete()` 物理清理。
