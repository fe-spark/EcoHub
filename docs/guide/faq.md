## 采集与使用

### 部署完成后前台为什么没有影片？

发布镜像不包含影视数据，首次启动只写入 12 个预设采集站，不会自动执行全量采集。

请登录管理后台，在「采集中心」执行一次全量采集。采集站越多耗时越长，首次采集可能需要数小时。无需等待全部完成：每当批次数据落库发布后，列表缓存会在几秒防抖后失效，主站影片随采集进度陆续出现在前台；搜索全量索引会在全部采集队列完成后统一更新。

### 什么是主站与海报源？

- **主站**：后台「主站」选择器指定的全局采集站。前台首页、分类、搜索和每日更新仅展示主站采集到的影片与分类。停用或删除主站时须同时指定新的主站；调整采集站排序不会改变主站。
- **播放页跨站聚合**：以主站影片为基准，自动从其他已启用采集站中查找同名匹配影片并把线路附在后面，按采集站分组显示。
- **海报源**：独立于主站的封面来源标记。前台优先使用海报源中匹配到的封面，未匹配到时回退为主站自身的封面。

### 切换主站会清除哪些数据？

不会清除任何数据。切换主站不删除影片、不重新采集，采集进行中也可以切换。

「首页轮播」和「首页推荐」均按采集站分别保存；切换后展示新主站的配置，切回原主站后自动恢复原有配置。与之不同，**修改采集站接口地址**或**删除采集站**会清理该站自身的影片、线路、失败记录与分类数据，其他采集站不受影响。

### 手动停止采集后数据处于什么状态？

停止操作会中断正在拉取的页。已成功入库的影片保留在片库中；正在写入的事务会完成落库，尚在队列等待写入的批次会被停止或丢弃。失败的页会记录在「采集记录」中，可在后台按批次或单页重试（超过 30 分钟后自动转为按失败站点重采）。

### 刮削结果、首页轮播和推荐如何保存？

- **影片刮削**：修改该影片所选的封面、简介、评分等字段并保留映射锁定，片名与分类保持不变；修改后不支持自动还原。
- **首页轮播与首页推荐**：在后台「首页管理」中按采集站分别维护，轮播编辑页手动修改的封面、简介、评分、年份不会影响片库原影片，也不会因日常采集被覆盖。绑定豆瓣或 Bangumi 榜单的推荐分组会在榜单更新或采集结束后自动按片库片名同步更新。

### 修改配置或入库后前台为何没有立即生效？

保存网站配置后会立即刷新首页缓存。如页面仍显示旧内容，常见原因如下：

- 浏览器、CDN 或反向代理存在缓存。
- 正在查询的非当前主站数据，或当前主站尚未采集任何影片。
- 列表、筛选与 TVBox 常规列表各有独立的短时或小时级缓存（采集流式入库后有约 5 秒防抖清理）；若出现短时差异，等待几秒或检查请求参数与站点实例是否一致。

## 网络代理

### 哪些请求走后台「网络代理」？

仅当后台「网络代理」（`/manage/system/proxy`）开启全局代理，且对应模块的开关也已开启时，该模块的请求才通过代理发出；其他情况一律直连。容器环境变量不影响出站请求。支持 `http://`、`https://`、`socks5://`、`socks5h://`。

| 模块（后台名称） | 涵盖的请求 | 全新安装默认值 |
| --- | --- | --- |
| 影视采集爬虫 | 采集站接口；每个采集站还需在编辑页单独开启「采集接口代理」 | 开启 |
| TMDB 刮削 | 对 TMDB 接口的请求（含后台连通测试），以及首页推荐的豆瓣 / Bangumi 榜单拉取 | 开启 |
| Telegram 机器人 | 通知推送与交互菜单回调轮询 | 开启 |
| 系统版本更新 | GitHub 版本检查 | 开启 |
| 弹幕抓取 | 弹弹play 官方接口或自建 danmu-api 的弹幕搜索与下载（含后台「测试」） | 关闭 |

「弹幕抓取」默认关闭，原因是自建 danmu-api 通常部署在内网，走代理反而无法连接。从旧版本升级时同样默认保持关闭。

示例：代理软件运行在宿主机的 `7890` 端口且需要弹弹play 官方接口走代理时，在后台代理地址填写 `http://host.docker.internal:7890`（容器内 `127.0.0.1` 指容器自身），打开全局开关并开启「弹幕抓取」。

## 弹幕

### 全网弹幕未显示时如何排查？

先在后台「网站配置」→「基本信息」→「弹幕系统配置」中使用「测试」按钮验证，再查看播放器弹幕输入框中的加载状态。

开启全网弹幕需同时开启「启用弹幕系统」和「自动嗅探全网弹幕」，并填写自建 danmu-api 地址或弹弹play 的 AppId 与 AppSecret。点击「测试」按钮会直接使用表单当前配置拉取第 1 集全网弹幕（不读写弹幕缓存，是否走代理取决于「弹幕抓取」开关）。

播放器控制条输入框左侧圆点与提示含义：

| 圆点 | 输入框灰色文字 | 含义 |
| --- | --- | --- |
| 灰色闪烁 | 弹幕加载中… | 正在拉取弹幕 |
| 绿色 | 共 N 条弹幕，说点什么吧 | 已加载本站与全网弹幕，悬停可查看全网条数 |
| 黄色 | 共 N 条弹幕，未找到全网弹幕 | 未匹配到影片或该集无全网弹幕 |
| 红色 | 全网弹幕加载失败 / 弹幕加载失败 | 超时、网络不可达、鉴权失败等，悬停查看用户向原因 |
| 不显示 | 共 N 条弹幕，说点什么吧 | 未开启全网弹幕，仅展示本站弹幕 |

### 弹幕设置会保存吗？窄屏播放会怎么适配？

会保存。开关、透明度、字号、速度、显示区域、弹幕类型与防重叠设置保存在当前浏览器中，切换剧集或重开页面沿用；更换浏览器或清理网站数据后恢复默认。

播放器根据自身显示宽度实时自适应排版（不区分设备标识）：

| 播放器宽度 | 控制条 | 加载状态 | 顶部/底部固定弹幕 |
| --- | --- | --- | --- |
| 小于 560 像素 | 收起弹幕输入框和网页全屏按钮（已处于网页全屏时保留退出按钮） | 弹幕开关右上角圆点，加载失败时画面简短提示一次 | 转为滚动弹幕避让显示 |
| 560–767 像素 | 显示输入框并自动收窄，收起网页全屏按钮 | 输入框灰色文字与圆点 | 转为滚动弹幕避让显示 |
| 768 像素及以上 | 完整控制条 | 输入框灰色文字与圆点 | 固定在顶部/底部 |

字号按标准大屏等比自适应缩放（小屏自动缩小、全屏适度放大），调整后会自动换算回基准字号保存；显示区域以播放器容器顶部为起点计算，在存在上下黑边时可利用黑边空间减少对正片画面的遮挡。

## 登录与权限

### 后台页面可以打开，但接口提示未登录怎么办？

前端只根据浏览器登录 Cookie 做初步放行，实际权限以服务端校验为准。同一账号在其他设备登录后，旧登录态会被顶替失效；或 Cookie 过期（默认 10 天有效）时，后续请求会返回未登录并跳回 `/login`，重新登录即可。

### 默认账号与不同角色如何划分？

首次启动只创建超级用户 `admin`，初始密码来自 `ECOHUB_ADMIN_PASSWORD`（默认 `admin`），首次登录后请立即修改。可在后台「账号管理」创建更多账号：

| 角色 | 权限 |
| --- | --- |
| 超级用户 | 全部操作，包括网站配置、账号管理与系统升级 |
| 普通用户 | 日常管理，不能执行仅限超级用户的操作 |
| 访客 | 只读，所有写操作请求均被拒绝 |

### 开启私有化访问后订阅怎么填？

在后台「网站配置」→「基本信息」→「运行与访问控制」中开启「私有化访问」后，须填写订阅密钥：

- 前台与前台接口：需要已登录，或携带正确的订阅密钥。
- 订阅地址（`/api/provide/app`、`/api/provide/tvbox`、`/api/provide/vod`）：必须携带订阅密钥。

密钥支持 URL 参数 `?key=` 或请求头 `X-Provide-Key`。示例（密钥 `mysecret888`）：

```text
http://<服务器IP>:3000/api/provide/tvbox?key=mysecret888
```
